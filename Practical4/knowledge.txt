Artificial Intelligence is a field of computer science that focuses on creating intelligent machines.

Machine Learning is a subset of Artificial Intelligence that allows computers to learn patterns from data.

Deep Learning is a subset of Machine Learning that uses neural networks with multiple layers.

Python is a popular programming language used in Artificial Intelligence and Machine Learning.

RAG stands for Retrieval Augmented Generation. It allows an AI system to retrieve relevant information from external knowledge sources before generating an answer.
